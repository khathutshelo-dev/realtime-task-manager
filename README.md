# Real-Time Collaborative Task Manager

A full-stack real-time task management system inspired by Trello. Built using Node.js, Express, PostgreSQL, and Socket.io.

## Features

- User Authentication (JWT)
- Workspaces, Boards, Columns, Tasks
- Real-time task updates using Socket.io
- Drag & drop task movement
- Live collaboration between users
- Activity logging system
- PostgreSQL relational database

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Socket.io
- HTML, CSS, JavaScript

## How to Run

```bash
npm install
node server.js
